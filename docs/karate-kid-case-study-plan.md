# Karate Kid: Legends × IMDb Creative Studio — Case Study Plan

Planning document for a **new** Work entry. This is not an edit to Lioness, Maria, Modular, or Vehicle Onboarding.

## Portfolio audit (how a new Work entry is added)

- Stack: Next.js 15 App Router, React 19, TypeScript, Tailwind v4 tokens in `src/app/globals.css`.
- Work entries live in `projects[]` inside `src/lib/content.ts`. Order in that array is display order on Home and `/work`.
- Tiles are generated by `ProjectCard` (`src/components/ProjectCard.tsx`): 16/10 media, `{year} · {role}`, title, subtitle. Hover lifts the card; focus uses the global `:focus-visible` ring. No separate hover-metadata overlay exists — do not invent one.
- Case-study route: `/work/[slug]` via `src/app/work/[slug]/page.tsx`. `generateStaticParams` reads `projects[]`. Sitemap includes every slug automatically.
- Case-study architecture: shared hero (breadcrumb, eyebrow, display title, lede, 3-col Role/Client/Year, 16/9 image or video) + slug-specific `*Body` + “More work” list. There is **no** previous/next pair — reuse More work, do not add a new nav pattern.
- Visual language: warm paper light / ink dark, Geist, `.eyebrow` / `.display` / `.lede` / `.prose`, 16px radii, `--line` borders, `--bg-elev` cards. Motion is restrained (card lift, 180ms). `prefers-reduced-motion` already zeroes animation/transition.
- Categories/tags: none. Do not create a new taxonomy. Encode discipline in `role` + `subtitle`.
- Dark/light: CSS variables; imagery is cinematic and works on both.

**Native addition path:** push a new object onto `projects[]` (first), add `karateKidCase` copy, render `KarateKidBody` from the existing slug page, place public images under `public/media/karate-kid/`.

## Interactive demonstrations

Portfolio-only teaching tools, labeled as such. Keyboard + touch. `aria-live` feedback. `prefers-reduced-motion` skips timing animations and keeps the mechanic readable.

- Precision: left/right block of a highlighted target  
- Balance: hold input to keep a marker in a zone  
- Memory: remember a Shift / Alt-style key combination, then repeat it
